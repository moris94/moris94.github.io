# デザインコンセプト

## 使ったスキル

Anthropic公式プラグイン `frontend-design`（`claude-plugins-official/plugins/frontend-design/skills/frontend-design/SKILL.md`）を読み込み、その手順に従った。

1. 題材・利用者・ページの役割を先に決める
2. 色（4〜6色の名前付きhex）、書体、レイアウト、原則で小さなトークン体系を作る
3. 計画を「どのサイトにも出てくる既定の見た目」と照合し、当てはまる部分を直す
4. 実装し、スクリーンショットで確認して直す

スキルの注意点のうち、特に次を守った。全大文字のラベルや見出し上の小見出し（eyebrow）を使わない。見出しの1語だけ色や太さを変えない。中黒（・）でメタ情報をつながない。ボタンの文言に「→」を付けない。連番は本当に手順になっている所だけで使う。動きは1か所だけにして、`prefers-reduced-motion` を尊重する。

## 共通の考え方

4つのアプリは、提供元が同じでも題材がまったく違う。共通のテンプレートに色だけを差し替えるのではなく、**各アプリの実画面と仕様書の色・言葉から、アプリごとに1つの見せ場を作る**。それ以外（ナビゲーション、文字組み、FAQ、フッター）は静かで共通の作りにして、保守しやすくする。

- 一次情報は本文のHTMLテキスト。画像の中の文字に頼らない
- スクリーンショットは公開中のApp Storeと同じ実画面を使う。端末フレームの画像は使わず、角丸と細い枠だけで囲む
- 書体はWebフォントを読み込まず、Apple端末に入っている書体を役割ごとに選ぶ（読み込みが速く、iPhoneで見たときにアプリと同じ文字になる）
- 左揃え。本文の行長は日本語で約38字、英語で約70字まで
- 余白と見出しの大きさで階層を作り、カードの多用と装飾の影を避ける

## アプリごとのトークン

### TaskBit: 棚の上の小さな部屋

題材: タスクを終えると相棒の部屋に家具が増えるToDoアプリ。利用者は「ToDoが続かない」人。アプリの色指定（`art-direction.md` v1.1）は純白・純黒を使わない北欧ポップ。

| 名前 | hex | 役割 |
|---|---|---|
| Plaster | `#FBF7EE` | 背景（アプリの `AppTheme.background`） |
| Linen | `#F3EBDD` | 面 |
| Oak | `#C9A46A` | 棚板・床の線 |
| Ink | `#4A4742` | 本文（アプリの `textPrimary`） |
| Sprout | `#4C7543` | リンク・ボタン（`accentGreen` をコントラスト確保のため暗くした） |
| Coin | `#E8B640` | コインの小さな印だけ |

- 書体: 見出しは Hiragino Maru Gothic ProN / Arial Rounded MT Bold（アプリの丸い形に合わせる）。本文は Hiragino Sans / システム書体
- 見せ場: ヒーローの実画面を**木の棚板の上に置く**。セクションの区切りは床と巾木の線。「入れる／完了する／部屋が育つ」は実際の手順なので番号を使う
- 照合で直した点: 最初は「クリーム背景＋セリフ見出し＋テラコッタ」のよくある組み合わせに近かった。セリフをやめて丸ゴシックにし、アクセントはアプリ本来の緑と木の色にした

### GeoAlbum: 半径の輪

題材: 保存した「場所ルール」（場所＋半径）で写真を見つけ、Apple「写真」のアルバムへ追加するユーティリティ。デザイン指針は「ネイティブに感じる、写真が主役、位置は道具でありブランドではない」。

| 名前 | hex | 役割 |
|---|---|---|
| Paper | `#F6F8FB` | 背景 |
| White | `#FFFFFF` | 面 |
| Ink | `#172033` | 本文 |
| Slate | `#566173` | 補足 |
| Geo Blue | `#3478F6` | 輪・図形（アプリのブランド色） |
| Geo Blue Deep | `#1B5FD1` | リンク・ボタン（白地でAAを満たす） |

- 書体: システム書体（SF Pro / Hiragino Sans）。数字は等幅数字
- 見せ場: ヒーローの実画面の背後に、**場所ルールの半径を表す同心円**を1つ描く（SVG）。地図や写真の装飾は足さない
- 照合で直した点: 写真アプリの紹介でありがちな「写真のコラージュ」をやめ、写真は実画面の中だけに出す

### StudyFocus（勉強集中）: 集中と休憩のリズム

題材: 集中中は選んだSNSをブロックし、休憩中だけ使えるようにするタイマー。デザイン指針は「Quiet Focus」。集中＝インディゴ、休憩＝グリーン。

| 名前 | hex | 役割 |
|---|---|---|
| Mist | `#F7F8F6` | 背景 |
| Graphite | `#181A18` | 本文 |
| Focus Indigo | `#4F5D95` | 集中（アプリをブロック中）、リンク・ボタン |
| Break Green | `#70A37F` | 休憩（アプリを使える）図形 |
| Break Green Deep | `#3C6E4C` | 休憩の文字 |
| Divider | `#E6E8E4` | 区切り |

- 書体: 時間の数字は `ui-rounded`（SF Pro Rounded）の細いウェイト。アプリのタイマーと同じ印象にする
- 見せ場: ヒーローに**集中と休憩を交互に並べた帯**を置き、どの区間で対象アプリがブロックされ、どこで使えるかを文字で示す。ページを開いたときに帯の上の印が一度だけ進む（動きはここだけ。動きを減らす設定では止める）
- 照合で直した点: 「大きな数字＋小さなラベル」の統計風ヒーローはやめた。数字は仕組みの説明のためだけに使う

### カエルート: 印刷した帰宅計画

題材: 平常時に職場・学校から自宅や集合場所までの徒歩ルートを準備し、オフラインと紙で参照する防災アプリ。アートディレクションは「Emergency Orange は面積を抑える。背景は暖かいニュートラル。チャコール」。

| 名前 | hex | 役割 |
|---|---|---|
| Map Paper | `#F2F1EC` | 背景 |
| Sheet | `#FFFFFF` | 計画書の紙面 |
| Charcoal | `#2A2A28` | 本文・見出し |
| Safety Orange | `#E8590C` | ルートの線（図形） |
| Safety Orange Deep | `#B8430A` | リンク・ボタン |
| Ready Green | `#2E7D4F` | 「保存済み」の状態だけ |

- 書体: 見出しは Hiragino Sans の太いウェイト（案内標識のように）。距離・時間は等幅数字
- 見せ場: ページの左端を**オレンジの徒歩ルートの破線**が縦に通り、「準備する／保存する／参照する」の各セクションを経由地のように結ぶ。ヒーローだけ方眼の地図用紙の地紋を敷く。「ご利用にあたって」の注意は太い枠で目立たせる
- 照合で直した点: 暖色の生成り＋赤茶は生成サイトの典型に近いので、紙をグレー寄りにし、オレンジは標識のオレンジに限定した

### 開発者トップ（moris94.github.io）

4つのアプリへの入口。白地にアイコンと1行の説明を並べるだけの静かな一覧にし、各アプリの見せ場と競わせない。

## 品質の下限

- モバイルファースト（360px〜）。タップ領域は44px以上
- キーボードのフォーカスを常に表示。本文へのスキップリンク
- 文字と背景のコントラストはWCAG AA以上
- 画像は幅360/720のWebP、`width`・`height` を指定してレイアウトのずれを防ぐ。ヒーロー以外は遅延読み込み
- JavaScriptはなし。すべての情報とリンクはHTMLだけで使える
